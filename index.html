2 Connecting Your Custom Domain (e.g. musas-ai.com)

  1. Buy your domain from a registrar like Namecheap, Cloudflare, or GoDaddy.
  2. In Vercel or Netlify, go to Project Settings > Domains and add your custom domain.
  3. Update your registrar's DNS records: set an A Record pointing to Vercel/Netlify's IP or a CNAME Record.

3 Securing API Keys via Vercel Serverless Functions

To hide secret keys from public browsers, Musa wraps API calls inside a serverless backend function:

// api/generate.js (Vercel Serverless Function)
export default async function handler(req, res) {
  const { prompt } = req.body;
  const apiKey = process.env.MUSA_CORE_API_KEY; // Stored securely in Vercel Env Variables
  
  const response = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/imagen-3.0-generate-002:predict?key=${apiKey}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ instances: [{ prompt }] })
  });
  
  const data = await response.json();
  res.status(200).json(data);
}
